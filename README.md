# KnzSound

Нативный клиент SoundCloud для Windows: свой плеер с эквалайзером и визуализатором, мини-виджет поверх экрана, виджет для OBS, статус в Discord и темы под себя.

## Скачать

Скачай установщик из раздела [**Releases**](https://github.com/kanzxza/KnzSound/releases) — файл `KnzSound-Setup-1.0.0.exe`.

> Исходный код не публикуется. В репозитории только описание и сборки.

## Возможности

- Плеер с эквалайзером и визуализатором
- Мини-виджет поверх экрана
- Виджет для OBS
- Статус в Discord
- Темы под себя

## Установка

1. Скачай `KnzSound-Setup-1.0.0.exe` из Releases
2. Запусти и установи
3. Открой приложение и слушай
