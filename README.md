# KnzSound — десктопный плеер SoundCloud для Windows

Лёгкий и быстрый клиент SoundCloud: вся твоя музыка, волна рекомендаций, плейлисты и лайки — в отдельном окне, без браузера и лишних вкладок.

## Скачать

Забирай установщик со страницы [**Releases**](../../releases) Только Windows 10/11 x64, ничего лишнего ставить не нужно.

## Что внутри

- **Всё ядро из коробки** — Главная, Моя волна в 4 режимах, Лента, Поиск, Профили, Лайки, Плейлисты и Очередь
- **Стеклянный интерфейс** — блюр-панели, акцент от обложки, светлая тема, свои обои, масштаб 85–125%
- **Звук под себя** — 10-полосный эквалайзер с 19 пресетами, бас-буст, 8D, баланс, моно, нормализация, скорость, питч, кроссфейд
- **Караоке на весь экран** — подсветка строк, сдвиг синхронизации, скраб по тексту, клипы с субтитрами
- **Статистика** — дни подряд, тепловая карта, топ треков, артистов и жанров
- **Мини-виджет поверх окон** с визуализаторами + OBS-оверлей для стримов
- **Обход блокировки** — Zapret и прокси из коробки, кнопка проверки связи
- **Discord-присутствие** — друзья видят, что ты слушаешь

Подробности каждой версии — во вкладке «Что нового» прямо в приложении и в описании релиза.
